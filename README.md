# java-lotto-precourse

## 구현 기능 목록

### 로또 로직
 - [x] 로또 1장 발행시 숫자범위(1 ~ 45)중 서로 중복되지 않는 당첨번호 6개와, 보너스 번호 1개를 추출한다.
 - [x] (구입 금액 / 1000)의 수 만큼 로또를 발행한다.
 - [x] 사용자가 구매한 로또 번호와 당첨번호를 비교하여 당첨내역 및 수익률을 계산한다. 이때 수익률은 소수점 둘째 자리에서 반올림한다.

### 입력 및 출력
 - [x] 로또 안내 문구를 출력한다. ("구입 금액을 입력해주세요.");
 - [x] 로또 구입 금액을 입력받는다.
 - [x] 당첨번호를 입력받는다. 이때 번호는 쉼표(,)로 구분한다.
 - [x] 보너스 번호를 입력받는다.
 - [x] 발행한 로또 수량 및 번호를 출력한다. 출력시 번호는 오름차순으로 정렬한다.
 - [x] 당첨 내역을 출력한다. 
 - [x] 수익률을 출력한다.

### 예외처리
 - [x] 모든 에러 메시지는 [ERROR]로 시작한다.
 - [x] 구입 금액이 숫자가 아니거나 공백 문자가 포함된다면 `[ERROR] 구입 금액에는 숫자만 포함되어야합니다다.` 를 출력한다.
 - [x] 구입 금액이 0 또는 음수라면 `[ERROR] 구입 금액은 0 이상이어야합니다.`를 출력한다.
 - [x] 당첨 번호가 6개가 아니라면 `[ERROR] 당첨 번호는 6개이어야합니다.`를 출력한다.
 - [x] 당첨 번호에 중복이 존재하면 `[ERROR] 당첨 번호는 서로 중복되지 않아야합니다.`를 출력한다.
 - [x] 당첨 번호에 숫자가 아니거나 공백 문자가 포함된다면 `[ERROR] 당첨 번호에는 숫자만 포함되어야합니다.`를 출력한다.
 - [x] 당첨 번호가 범위인(1 ~ 45)에 포함되지 않을 경우, `[ERROR] 당첨 번호는 (1 ~ 45)사이의 숫자여야합니다.`를 출력한다.
 - [x] 보너스 번호가 1개가 아니라면 `[ERROR] 보너스 번호는 1개여야합니다.`를 출력한다.
 - [x] 보너스 번호가 숫자가 아니거나 공백 문자라면 `[ERROR] 당첨 번호는 숫자여야합니다.`를 출력한다.
 - [x] 보너스 번호가 당첨번호 중 중복이 존재한다면 `[ERROR] 보너스 번호는 당첨번호와 중복되선 안됩니다.`를 출력한다.
